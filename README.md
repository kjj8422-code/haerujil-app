# haerujil-app

야간 해루질(맨몸 스킨 다이빙·물놀이 채집) 참가자가 법적인 문제를 피할 수 있도록 돕는
스마트폰 앱 — [jeju-harbor-map](https://github.com/kjj8422-code/jeju-harbor-map)(제주
한정 웹사이트)의 후속작으로, 전국 규모로 확장한 프로젝트입니다.

금어기·금지체장, 제주 입수금지구역(2027년 시행 예정), 전국 스킨 해루질 금지구역(수상레저
안전법), 안전관리요원 인정단체 정보를 앱 하나로 확인할 수 있습니다.

- 기술 스택·설계 결정: [`CLAUDE.md`](CLAUDE.md)
- 데이터베이스 설계: [`docs/DATA_DESIGN.md`](docs/DATA_DESIGN.md)
